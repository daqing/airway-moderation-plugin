# Words that survive the mechanical filters but must not screen chat.
#
# The upstream lists were built for search engines and content sites, where a
# keyword like 兼职 or 高潮 is a useful signal. Here every hit holds a message
# for a human to review, so a word earns its place only when its ordinary,
# harmless use is rare.
#
# One word per line; blank lines and lines starting with # are ignored. A word
# listed here is dropped from every category. Words that are nothing but ASCII
# junk (www, 64, 189, CCTV) are handled by the length floors in main.go and do
# not belong here.
#
# Anything an operator disagrees with can be removed from this file: rerun
# `go run ./tools/lexicon` and the generated list follows.
